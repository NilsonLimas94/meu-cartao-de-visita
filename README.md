> Cartão de apresentação pessoal interativo em estilo Dark Theme com profundidade 3D, efeito tilt responsivo aos movimentos do mouse e anel gradiente animado.

## ✨ Funcionalidades e Efeitos

- **🎮 Efeito 3D Tilt Interativo:** O cartão se inclina dinamicamente em três dimensões conforme a posição do mouse sobre o elemento, retornando suavemente ao centro quando o cursor se afasta (`mouseleave`).

- **🌀 Borda Giratória Contínua:** Halo circular com `conic-gradient` que gira em 360° sem interrupções via animação CSS pura acelerada por GPU (`@keyframes`).
- **🎨 Glassmorphism & Dark Mode:** Paleta de cores moderna com transparências `rgba()`, sombras suaves (`box-shadow`) e bordas translúcidas.

- **⚡ 100% Vanilla:** Desenvolvido do zero sem bibliotecas, frameworks ou dependências pesadas — apenas HTML, CSS e JavaScript nativos.

## 🛠️ Tecnologias e Conceitos Praticados

| Tecnologia | O que foi aplicado |
|---|---|

| **HTML5** | Estruturação semântica com `<main>`, `<header>`, divisores e links acessíveis. |

| **CSS3** | Flexbox, `@keyframes`, gradientes lineares e cônicos, `perspective`, `transform-style: preserve-3d`, filtros e transições suaves. |

| **JavaScript (ES6+)** | Manipulação do DOM (`querySelector`), cálculo matemático de coordenadas (`getBoundingClientRect`, `clientX`, `clientY`) e ouvintes de eventos (`mousemove`, `mouseleave`, `mouseenter`). |

## 🚀 Como Executar Localmente

Como o projeto é construído em tecnologia web pura, não requer instalação de pacotes (`npm` ou `yarn`):

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/NilsonLimas94/meu-cartao-de-visita.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd meu-cartao-de-visita
   ```

3. **Abra o arquivo `index.html`:**
   - Dê um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador preferido;

   - Ou utilize a extensão **Live Server** no VS Code para recarregamento automático.
